# 需求工程评审专家

基于大模型的智能需求质量评审工具，输入需求文本即可自动输出质量评分、问题诊断和修改建议。

## 技术栈

- **大模型**：DeepSeek Chat API（兼容 OpenAI 接口格式）
- **框架**：LangChain + Gradio
- **知识库**：IEEE 830 软件需求规格标准 + 需求反模式清单

## 功能特性

- **结构化评审**：模型返回 JSON 结构化结果，前端渲染为专业评审工作台
- **四维评分**：完整性、无歧义性、可验证性、可追踪性，0-10 分制
- **问题诊断**：按高/中/低优先级列出问题，含位置、原因、影响、标准依据
- **原文对照改写**：每个问题提供原文与建议改写对照，一键复制
- **验收标准**：每个问题附带可执行的验收验证方法
- **完整改写**：整合所有修改后的完整需求文本，可直接复制使用
- **步骤条引导**：输入需求 → 智能评审 → 查看结果，三步流程
- **示例快速体验**：内置三类示例需求，一键填充
- **加载动画**：评审过程显示骨架屏加载效果

## 快速开始

### 环境要求

- Python 3.10+
- DeepSeek API Key（申请地址：https://platform.deepseek.com/）

### 安装步骤

1. **克隆或下载项目**

2. **创建虚拟环境并激活**

```bash
python -m venv venv
# Windows
venv\Scripts\activate
```

3. **安装依赖**

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

4. **配置 API Key**

复制 `.env.example` 为 `.env`，填入你的 DeepSeek API Key：

```env
DEEPSEEK_API_KEY=sk-你的API密钥
```

5. **运行程序**

```bash
python app.py
```

启动后终端会显示访问地址，默认是 `http://127.0.0.1:7860`，在浏览器打开即可使用。

## 使用说明

### 评审流程

1. **输入需求**：在左侧文本框粘贴需求文本，或点击右侧示例快速填充
2. **开始评审**：点击「开始智能评审」按钮，等待分析完成
3. **查看结果**：
   - 顶部：质量总分、等级、四维评分、问题优先级统计
   - 左侧：问题导航列表，点击切换查看不同问题
   - 右侧：当前问题的详细诊断（位置、原因、影响、依据）
   - 底部：原文/改写对照、验收标准、完整改写版本

### 示例需求

内置三类示例：
- **模糊需求**：登录时限与主观描述
- **可量化需求**：网络、设备与响应时间
- **复杂条件需求**：并发、体验与数据量

点击即可填充到输入框，快速体验评审效果。

## 评审标准

依据 IEEE 830 软件需求规格标准，从四个维度评审：

| 维度 | 说明 |
|---|---|
| 完整性 | 需求是否描述了所有必要的功能、性能和异常处理 |
| 无歧义性 | 术语是否明确定义，是否存在多种理解可能 |
| 可验证性 | 需求是否可测试、可量化，是否有明确的验收标准 |
| 可追踪性 | 需求是否有唯一标识符，是否可追溯到设计和测试 |

## 配置说明

可通过环境变量修改以下配置：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | - | DeepSeek API 密钥（必填） |
| `GRADIO_SERVER_PORT` | `7860` | 服务端口 |
